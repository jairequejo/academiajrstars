# Iconos PWA del entrenador

`icon-source.png` es el maestro de alta resolución basado en el escudo oficial de JR Stars. Los demás PNG son derivados destinados al manifiesto, Android, iOS y navegadores; no deben redimensionarse entre sí porque se acumularía pérdida de calidad.

| Archivo | Uso |
| --- | --- |
| `icon-192.png` | Icono PWA estándar de 192 px |
| `icon-512.png` | Icono PWA estándar de 512 px |
| `icon-maskable-512.png` | Icono Android con margen seguro |
| `apple-touch-icon.png` | Acceso directo en iOS |
| `favicon-48.png` | Pestaña del navegador |
